## About

This is a rebrand and rebuild of my previous portfolio.

I wanted a breathing, soft aesthetic. I experimented a lot with
animations using AI tools, online libraries, and whatever little ideas
I had in my imagination.

Apparently, I enjoy making websites about the fact that I make websites.

> The site features:

- 🪽 Web projects with live sandbox
- 🪷 A longform biography (in case you like loremaxxing)
- 🦋 Interactive 3D model
- 🌱 Ported terminal / CLI for my .py and .asm little exercises
- 📜 A small art and literature collection
- 🧸 Custom interactions and visual experiments
